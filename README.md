# Nikola Lapić — sajt

Ovo je početna verzija sajta za Nikolu Lapića, slikara naive iz Starčeva.

## Struktura

- `index.html` — sadržaj sajta
- `style.css` — izgled i stil
- `images/` — fotografije
- `README.md` — kratko uputstvo

## Kako se dodaju slike u galeriju

Kada budeš imala fotografiju slike, možemo dodati karticu u `index.html` sa:
- nazivom dela
- tehnikom
- dimenzijama
- godinom nastanka
- statusom (ako želite: dostupno/prodato)
- većom fotografijom koja se otvara klikom

## GitHub Pages

1. Napravi GitHub nalog.
2. Napravi novi repository, npr. `nikola-lapic`.
3. Ubaci sve fajlove iz ovog foldera.
4. U repository-ju otvori Settings → Pages.
5. Kao source izaberi `Deploy from a branch`, branch `main`, folder `/root`.
6. GitHub će napraviti javnu adresu za sajt.

Kasnije možemo povezati i sopstveni domen, npr. `nikolalapic.rs`, ako budete želeli.


Galerija sadrži 10 izabranih radova sa nazivima, dimenzijama i uvećanim prikazom.
